📋 项目简介

LarkReader 解决一个具体问题：把飞书知识库变成你硬盘上可直接阅读、离线可用的文件。递归遍历知识库，Doc → Markdown（图片本地化）、Sheet → XLSX、Bitable → NDJSON、file 附件 → 原样字节，整棵目录树按飞书层级与排序落盘。纯本地运行、数据不出机、无遥测。

🚀 快速开始

前置要求

  • ✅ Node.js 18+
  • ✅ Rust (stable)
  • ✅ @larksuite/cli（应用内自动安装）
Bash
# 安装前端依赖
npm install

# 开发模式运行
npm run tauri dev

# 构建生产包
npm run tauri build

# 验证
npm run verify

首次运行会自动检测 lark-cli 并引导登录。

⚡ 核心功能

能力说明
单文档导出接受 Wiki URL 或节点 token，Markdown + 图片并发下载并本地化
Wiki 递归导出保留目录层级与排序，循环/深度≤64/节点≤10000 三重保护
表格导出Sheet→XLSX，Bitable→NDJSON + manifest.json
文件附件按原始字节下载，字节数与上传一致
后台任务8 阶段进度，协作式取消，历史持久化（24h/≤100 条）
本地阅读Reader 页浏览导出目录，渲染 Markdown 与图片
应用更新公钥签名校验，Windows/macOS/Linux 自动安装
可靠性结构化错误协议、预检、回滚、指数退避重试
