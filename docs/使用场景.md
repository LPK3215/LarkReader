# 使用场景

> 一些文档内部资源比较多，内容比较多；对网络环境要求比较高，对阅读环境要求也比较高。使用 LarkReader，可以方便地预览文档，并使用阅读模式方便地阅读。

## 场景痛点

在日常协作中，飞书知识库经常会遇到这类情况：

- 文档内部资源多、内容体量大，在线查看容易卡顿；
- 网络环境不稳定或访问受限，页面加载慢甚至打不开；
- 阅读环境受限，需要更舒适、更专注的阅读体验。

当知识库开启了"仅允许特定成员导出"的安全设置后，普通成员打开文档时可能会看到大量权限提示，导致关键内容在标准导出入口中无法处理，只剩"在线浏览"一种交互方式。

![飞书知识库安全设置示例](./image.png)

上图正是这种典型场景：左侧目录树结构完整、节点清晰，但右侧正文区域被权限提示占据。此时即便你拥有阅读权限，平台原生工具在数据自主层面也无能为力。

## LarkReader 的定位

LarkReader 为应对这种场景而设计：基于飞书官方公开的标准授权与数据通道，把你有权限访问的知识库内容完整保留到本地，全程不接触账号安全机制。

1. **本地导出**：按飞书目录结构，把允许你访问的文档与资源下载到本地；
2. **离线预览**：导出后的 Markdown 与附件可断网预览，不再依赖实时网络；
3. **阅读模式**：提供适合长时间阅读的排版，减少干扰，提升阅读效率；
4. **数据自主**：所有内容落盘在用户本机，备份与归档由用户自行决定。

## 使用路径

1. 打开 LarkReader，使用你自己的飞书账号完成标准授权；
2. 选择要导出的知识库与节点；
3. 启动导出任务，等待进度完成；
4. 在历史记录中打开导出的本地目录即可随时阅读。

## 适合谁用

- 知识库被设置了较高的安全等级，平时只能用 Web 端浏览；
- 经常出差 / 在网络受限的环境下需要参考已有资料；
- 希望为团队的知识库建立一份本地留档，用于长期的备份与回顾。
