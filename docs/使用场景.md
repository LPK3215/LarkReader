# 使用场景

> 一些文档内部资源比较多，内容比较多；对网络环境要求比较高，对阅读环境要求也比较高。LarkReader 是飞书知识库的本地阅读器，把内容留到本地，用更顺手的方式阅读。

## 你平时在浏览器里看飞书知识库，是不是这样的体验

- **多 tab 来回切换**：左侧目录、右侧正文、评论、版本历史、资源预览，一篇文档要开好几个页面才能看全；
- **加载受网络影响**：网速不稳、跨网访问、页面里资源多时，加载慢、转圈久，正文断断续续；
- **搜索 / 跳转能力弱**：浏览器通常只能按标题搜，正文里出现过的关键词找不到；跨文档跳转要靠手动搜索；
- **没有"阅读模式"**：导航栏、按钮、状态栏都在屏幕上，长文阅读容易分神；
- **离线基本不能用**：出差、路上、网络受限的环境里几乎看不了。

## LarkReader 是什么

飞书知识库内容备份工具 + 内置本地阅读器，一次扫描把整个知识库的内容、目录、附件落到本机，再用一个统一界面读起来更顺手。

| 在浏览器里 | 用 LarkReader |
| --- | --- |
| 多 tab 来回切 | 一个窗口，左侧目录、右侧正文、附件预览一体化 |
| 受网络影响、加载卡顿 | 本地 Markdown 与资源落盘，断网可读 |
| 全文搜索弱 | 内置正文检索与标题定位 |
| 没有阅读模式 | 大字号、暗色、隐藏干扰的阅读视图 |
| 不能离线 | 导出一次，断网后照常翻阅 |

## 使用路径

1. 用自己的飞书账号完成标准授权；
2. 选择要保留到本地的知识库与节点；
3. 启动导出任务，等待进度完成；
4. 在 LarkReader 中打开历史记录、进入阅读模式。

## 长期效果

- **阅读效率高**：目录、正文、附件集中呈现；
- **不被网络状态左右**：本地化翻阅，地铁、出差、路上都可用；
- **长文沉浸**：阅读模式去除无关元素；
- **可检索**：标题、正文都可搜，跳回原文更高效；
- **可归档**：内容落盘在用户本机，备份与组织由用户自行决定。

## 适合谁用

- 知识库内容多、目录深，平时主要在线浏览；
- 经常在网络受限 / 不在办公室的环境下翻查已有资料；
- 想用更适合长时间阅读的工具替换浏览器；
- 想给团队资料做一份长期可读的本地留档。
