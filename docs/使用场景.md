# 使用场景

> 一些文档内部资源比较多，内容比较多；对网络环境要求比较高，对阅读环境要求也比较高。LarkReader 作为飞书知识库的本地阅读器，把内容留到本地后再用更顺手的方式阅读。

## 在浏览器里阅读飞书知识库，常常是这样的体验

- **多 tab 来回切换**：左侧目录、右侧正文、评论、版本历史、资源预览，一篇文档要开好几个页面才能看全；
- **加载受网络影响**：网速不稳、跨网访问、页面里资源多时，加载慢、转圈久，正文断断续续；
- **搜索 / 跳转能力弱**：浏览器通常只能按标题搜，正文里出现过的关键词找不到；跨文档跳转也要靠手动搜索；
- **没有"阅读模式"**：导航栏、按钮、状态栏都在屏幕上，长文阅读容易分神；
- **离线基本不能用**：出差、路上、网络受限的环境里几乎看不了。

## LarkReader 的解决方式

LarkReader 把"把知识库内容从云端留到本地、给一个更顺手的阅读环境"作为核心定位。

| 在浏览器里 | 用 LarkReader |
| --- | --- |
| 多 tab 来回切 | 统一阅读界面，左侧目录 + 右侧正文 + 附件预览一体化 |
| 受网络影响、加载卡顿 | 本地 Markdown 与资源落盘，断网可读 |
| 全文搜索弱 | 内置正文检索与标题定位 |
| 没有阅读模式 | 提供大字号、暗色、隐藏干扰的阅读视图 |
| 不能离线 | 导出一次，断网后照常翻阅 |

**画面举例：内容多、安全等级高的知识库页面**

在内容多、安全设置较高的飞书知识库里，浏览器里的有效信息往往被各种提示、权限面板挤占，正文区域很难沉浸地看下去。

![飞书知识库页面浏览示例](./image.png)

这种情形下，与其让浏览器被动渲染，不如把内容拿出来用专门的阅读器看。

## 使用路径

1. 用自己的飞书账号完成标准授权；
2. 选择要保留到本地的知识库与节点；
3. 启动导出任务，等待进度完成；
4. 在 LarkReader 中直接打开历史记录、进入阅读模式。

## 效果

- **不再被网络状态左右**：本地化阅读，不再依赖实时网络；
- **不再依赖多 tab 切换**：目录、正文、附件收在一个窗口里；
- **长文可以沉浸看**：阅读模式去除无关元素干扰；
- **可检索**：标题、正文都能搜，跳回原文更高效；
- **可归档**：所有内容落盘在用户本机，备份与组织由用户自行决定。

## 适合谁用

- 知识库内容多、目录深，平时主要在线浏览；
- 经常在网络受限 / 不在办公室的环境下翻查已有资料；
- 想用更适合长时间阅读的工具替代浏览器；
- 想给团队资料做一份长期可读的本地留档。
