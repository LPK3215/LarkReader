# 人工验收清单（发布后照单全测）

> 用途：安装包发布后，照此清单把每个功能亲手过一遍，全勾完再对外宣传。
> 有任何一项不符合预期，记录现象 + 复现步骤，提 Issue 或回到开发修复。
> 详细操作说明见 [USER_GUIDE.md](USER_GUIDE.md)。

## 0. 安装与启动

- [ ] 从 GitHub Releases 下载对应平台安装包，**安装过程无报错**
- [ ] Windows：MSI/NSIS 安装后桌面/开始菜单出现图标，启动白屏时间可接受
- [ ] 应用启动进入引导页，窗口尺寸正常、缩放无错位
- [ ] 系统托盘/关闭行为符合预期，无残留后台进程

## 1. 首次引导（三步）

- [ ] **环境体检**：Node.js / lark-cli 检测通过；断网或未装 Node 时给出可读的异常提示（共 5 种异常分支至少抽查 2 种）
- [ ] **lark-cli 安装**：干净环境验证自动安装 `@larksuite/cli@1.0.93`
- [ ] **应用配置**：向导自动弹浏览器完成 `config init --new`，无需手动输入
- [ ] **登录**：设备码登录成功，界面显示已登录态；重复启动不要求重复登录

## 2. 单文档导出

- [ ] 粘贴完整 Wiki URL 导出成功，正文为 Markdown、图片本地化（`_images` 目录）
- [ ] 粘贴**纯 token** 效果一致
- [ ] 带查询参数 / 尾斜杠的 URL 正常解析
- [ ] 同一文档导出到同一目录两次：自动 `(2)` 编号，不覆盖旧文件
- [ ] 输出目录改成无权限 / 剩余空间不足的路径：有预检错误提示，不产生半截文件

## 3. 知识库递归导出

- [ ] 选单个节点：Auto 模式只导出本节点
- [ ] 选文件夹：FullSpace 模式展开整棵树，目录层级与飞书一致
- [ ] 树形勾选：多选 / 全选 / 反选 / 类型筛选正常
- [ ] 大列表性能：>100 节点的库不卡死
- [ ] 同名知识库导出到同一父目录：原子建目录不互覆

## 4. 各类型节点

- [ ] **docx** 正文 + 内联图片完整
- [ ] **Sheet** → XLSX 可用 Excel/WPS 打开
- [ ] **Bitable** → NDJSON + `.manifest.json`，记录数与线上一致
- [ ] **file 附件**：zip/pdf/docx 等字节数与原文件一致，文件名带位置前缀

## 5. 后台任务

- [ ] 导出大库时任务立即返回，界面可继续操作
- [ ] 8 阶段进度：总数 / 完成数 / 当前标题 / 预计剩余时间更新正常
- [ ] **中途取消**：任务停止并返回部分结果，不留半截文件
- [ ] 历史记录持久化：重启应用后仍在（24 小时 / ≤ 100 条）

## 6. 本地阅读（Reader）

- [ ] 打开导出目录：目录树展示、层级正确
- [ ] Markdown 渲染：标题/列表/代码块/表格/图片（含 data URL 内联）
- [ ] **断网状态**下阅读无任何异常
- [ ] 图片目录中图片正常显示

## 7. 设置与可靠性

- [ ] 输出目录 / 并发数 / 图片下载开关修改后持久化（重启保留）
- [ ] 运行日志页能看到结构化日志
- [ ] 错误提示均为中文、无原始 JSON 泄露（可用无效链接验证）
- [ ] 垃圾输入（空串、乱码、错误域名）不崩溃，返回友好错误

## 8. 应用内更新（发 v0.2.0 后回测）

- [ ] 设置页「检查更新」能发现新版本
- [ ] 下载进度可见、可取消
- [ ] 签名校验通过，安装后版本号更新
- [ ] Windows 自动重启 / macOS Linux 自动 relaunch

## 9. 卸载与收尾

- [ ] 卸载后系统无残留注册表项/服务（Windows 可用 CCleaner 抽查）
- [ ] 应用数据目录位置合理（%APPDATA% 等），删除干净

---

**全绿之后再做对外宣传**。发现问题时在本文档对应项打 ❌ 并补一行现象描述。
