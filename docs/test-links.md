## 二、判定规则（预期结果）

- **Auto（仅导出本节点及子树）** = 该节点自身 + 它在目录树中的**真实子节点**
  - 节点无子节点 → 结果应为 **1 个节点**，且界面出现引导提示条
- **FullSpace（展开整个知识库，含兄弟节点）** = 整个知识库空间的全部顶层节点及其后代
  - **关键判定：三条链接在 FullSpace 下应得到完全相同的整库树**（约 8 个顶层节点、30+ 项）
  - 你贴的那个节点会按真实层级出现在树中
